# On Air — the desktop app (developer notes)

What the app does, for people who use it: **[docs/desktop-app.md](../docs/desktop-app.md)**
and **[docs/interface.md](../docs/interface.md)**. This page is for working on it.

Electron 45, CommonJS, no bundler, no framework. Windows and Linux (Mac builds
from the same code, unsigned).

## Run, test, build

```bash
cd app
npm install
npm start            # run it
npm test             # the live watcher, against pretend stations
npm run skins        # copy the looks from the FunpostFM page (sync-skins.js)
npm run icons        # redraw icons/ after changing make-icons.js
npm run dist:win     # dist/On-Air-Setup.exe        (on Windows)
npm run dist:linux   # dist/On-Air-x86_64.AppImage and On-Air-amd64.deb (on Linux)
```

Installer names have no version in them on purpose, so
`releases/latest/download/On-Air-Setup.exe` always fetches the newest.

**Releasing:** bump `version` here, commit, push, then push a matching tag
(`git tag v0.4.2 && git push origin v0.4.2`). `.github/workflows/build-app.yml`
builds Windows and Linux on GitHub's machines and publishes the release with
`latest.yml` / `latest-linux.yml`, which every installed app's updater reads.

## How it's put together

| File | |
|---|---|
| `main.js` | Windows, the tray, settings (`config.json` in userData), IPC, downloads, the board view, the Interface's requests, updates. |
| `preload.js` | The only bridge between the app's pages and the computer (`window.onairApp`). Sandboxed. |
| `watch.js` | Finds a station from any address and watches whether it's live (plain Node). |
| `updates.js` | electron-updater against GitHub releases. |
| `userscripts.js` · `board-preload.js` | Board userscripts: install/update/remove, and the GM_* shim injected into the board's own view. |
| `ui/` | The app's own pages, served from `onair://app/`. |
| `ui/core.js` | The station client (ported from the listener page): one engine socket, the stream, the album player, calls. |
| `ui/radio.*` | The main window. |
| `ui/win.*` | Every other window (`win.html?w=chat` …); `ui/iface.*` is the Interface. |
| `ui/hall.*` · `ui/hall-art.js` | The Hall (🕺 in Chat's title bar): the pixel room, its people and Radioman, drawn from code on a 240×150 canvas. |
| `ui/common.js` | The frame, title bar, sheets, toasts, looks — shared by all windows. |
| `ui/skins.css` · `ui/look-data.js` | Generated by `sync-skins.js` from the FunpostFM page. |

**One process.** The radio opens every other window with `window.open`, so they
share its renderer and read `window.opener.core` — one connection to the
station no matter how many windows are open. Child windows need
`webPreferences` passed explicitly in `overrideBrowserWindowOptions` or they
get no preload.

**The board** is a `WebContentsView` (partition `persist:board`) laid over the
board window's slot; the page sends its bounds. An iframe can't load 4chan's
captcha (third-party context); a view can.

**The Interface** reads 4chan's read-only API and funposters.club through
main (`get-json`, `iface-req`, which only reaches funposters.club and the
green-thread server). Main adds the person's private key (`cfg.ifaceKey`) to
green-thread requests, and the moderator token only for the server it was saved
for (`station` = wherever the station PC is today, from its pointer).

**The Hall** rides the radio's station socket (`hall-*` messages, see
`engine/hall.js`): the engine sends where people are heading and each app
walks them there. What you say is ordinary station chat tagged with your Hall
id, so it shows as a bubble. Your look is kept in `localStorage` (`ltl.hallLook`).

## Test runs

Test runs leave your own settings alone and quit by themselves:

```bash
ONAIR_SMOKE=20000 ONAIR_USERDATA=./tmp-userdata ONAIR_STATION=esfores.neocities.org npx electron .
```

| Switch | |
|---|---|
| `ONAIR_SMOKE=ms` | Muted, quits after that long. No updater. |
| `ONAIR_SMOKE_SHOW=1` | Show the windows. |
| `ONAIR_SMOKE_OPEN=chat,albums` | Open windows (`ONAIR_SMOKE_OPEN_AT` = when). |
| `ONAIR_SMOKE_SHOT=dir` | A picture of each window (`ONAIR_SMOKE_SHOT_AT`), plus `board-view.png`. |
| `ONAIR_SMOKE_CHECK=js` | Run JS in every window and print the result (`ONAIR_SMOKE_CHECK_AT`). |
| `ONAIR_SMOKE_BOARD_JS=js` | Run JS in the board's view (`ONAIR_SMOKE_BOARD_AT`). |
| `ONAIR_SMOKE_FRAMES_JS=js` | Run JS in every window's frames — the TV's YouTube player, say — every `ONAIR_SMOKE_FRAMES_EVERY` ms. |
| `ONAIR_SMOKE_BUSY=ms` | Keep the main process busy that long every second. |
| `ONAIR_EXTRAS=file` | Use this extras.json instead of the published one. |
| `ONAIR_STATION=address` | A station to add on a fresh profile (a page, a pointer, or an engine). |

Never point test runs at a real station's studio.
